# 大六壬即时起课

Clock from parent `SKILL.md`. 月将加占时超天盘。

## 天地盘

地盘固定 子丑寅卯辰巳午未申酉戌亥。
天盘：月将加于占时之地盘位，顺布十二支。

## 四课

日干寄宫：甲寅 乙辰 丙巳 丁未 戊巳 己未 庚申 辛戌 壬亥 癸丑。

1. 一课 干上神 = 寄宫地盘上的天盘神
2. 二课 干阴神 = 一课上神之地盘上的天盘
3. 三课 支上神 = 日支上的天盘
4. 四课 支阴神 = 三课上神之地盘上的天盘

下贼上 = 下五行克上；上克下 = 上克下。

## 三传（九宗门，先到先取）

1. 有下贼上 → 重审；多枚则比用（阳日取阳神，阴日取阴神），再多则涉害深者。
2. 无贼有上克 → 元首，同样比用/涉害。
3. 无克看二、三课与日干遥克。
4. 四课不全 → 别责（阳日干合寄宫之神，阴日支前三位）。
5. 干支同位 → 八专（阳日一课上神顺三，阴日四课上神逆三）。
6. 月将=占时 → 伏吟；月将冲占时且无克 → 返吟无依（井栏射，阳日取酉上神）。
7. 否则昴星：阳日取酉上神为初，阴日取酉本身。

中传 = 初传上神，末传 = 中传上神（昴星/别责按各法）。
