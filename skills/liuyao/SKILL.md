# 六爻即时起卦

Use the parent `SKILL.md` clock. Default method is **时间起卦**.

## 时间起卦（先天八卦数）

先天数：1乾 2兑 3离 4震 5巽 6坎 7艮 8坤。余 0 作 8 坤。

- 上卦 = (年支数 + 农历月 + 农历日) mod 8
- 下卦 = (年支数 + 农历月 + 农历日 + 时支数) mod 8
- 动爻 = (同上总和) mod 6；余 0 为上爻。爻序初→上 = 1…6

年支数 子1 … 亥12。时支同。

爻值：静阳 7、动阳 9、静阴 8、动阴 6。动爻阴阳反转得变卦。

三才铜钱：每爻三钱，字=2 背=3，和为 6/7/8/9，自初爻摇至上爻。

## 装卦

纳甲（初→上）：

- 乾内 甲子甲寅甲辰 / 外 壬午壬申壬戌
- 坤内 乙未乙巳乙卯 / 外 癸丑癸亥癸酉
- 震内 庚子庚寅庚辰 / 外 庚午庚申庚戌
- 巽内 辛丑辛亥辛酉 / 外 辛未辛巳辛卯
- 坎内 戊寅戊辰戊午 / 外 戊申戊戌戊子
- 离内 己卯己丑己亥 / 外 己酉己未己巳
- 艮内 丙辰丙午丙申 / 外 丙戌丙子丙寅
- 兑内 丁巳丁卯丁丑 / 外 丁亥丁酉丁未

八宫飞伏：本宫→依次变初至五为五世；游魂翻回第四爻；归魂内卦复原。世爻：本宫上、一世初、二世二、三世三、四世四、五世五、游魂四、归魂三。应 = 世+3。

六亲（宫五行 vs 爻五行）：同兄弟、生我父母、我生子孙、我克妻财、克我官鬼。

六神起日干：甲乙青龙、丙丁朱雀、戊勾陈、己螣蛇、庚辛白虎、壬癸玄武，自初爻顺布。

用神：财→妻财；官考→官鬼；婚恋→妻财；病药子女→子孙；宅文书父母→父母；未明则以世爻。
